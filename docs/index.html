What it does

It mirrors Maps. It doesn't route.

Every maneuver

Turn left/right, sharp turns, keep left/right, forks, roundabouts, U-turns and arrival — drawn as a clean dot-matrix arrow.

Distance to the turn

Scrolls beneath the arrow — “300m”, “1.5k” — counting down as you approach.

No setup, no keys

Reads directions straight from Google Maps' Live Updates notification. No API key, no account, no sign-in.

Gives the Matrix back

Only claims the display while you're actually navigating. End the route and your usual Glyph toy returns.

Runs in the background

The app doesn't need to stay open. Start a route, flip the phone over, drive.

Yours to change

Independent head and tail LED brightness, plus Static Glow or Sweeping Flow display modes.

It cannot phone home

Not a promise — a property of the build.

GlyphMaps does not request the INTERNET permission. There is no network code, no analytics, no crash reporter, no advertising SDK and no server. Maps' navigation text is parsed in memory, turned into an arrow, and discarded. You can verify every line of that — the source is public.

Requirements

  • Nothing Phone (4a) Pro — the model with the circular 137-LED Glyph Matrix
  • Android 14 or newer (minSdk 34)
  • Google Maps with Live Updates — on by default in recent versions
  • Notification access granted to GlyphMaps
Phone (3) isn't supported. Its Glyph Matrix is a different panel — 489 LEDs on a 25×25 grid — and GlyphMaps renders for the (4a) Pro's 13×13. It's a renderer change rather than a rewrite, so if there's demand it may land later.

Getting started

  1. Install — download the APK and tap to install (allow Install from unknown sources if prompted), or adb install it. You can also build from source.
  2. Grant notification access — the app links you straight to the system setting on first launch. This is how it reads Maps' live directions, so it's required. It's filtered to the Google Maps package and the navigation category; everything else is ignored.
  3. Navigate — open Google Maps, start any route, flip your phone over. The Matrix lights up with your next turn.
Only one Glyph-Matrix app at a time. If you run another app that drives the Matrix from notifications, grant notification access to just one of them — two listeners will fight over the display during navigation and the arrow will flicker.
